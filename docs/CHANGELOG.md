# Changelog

Dates are the days the files were last edited. Times are UTC.

## 2026-11-17: Issue list "v2"

- Featured Organization panel now has a black background like Happening Now
- Built-in sample posts support like, dislike and comments
- Message unread badge grows with the count and shows `9+` above nine
- Tapping a notification opens the matching screen (a message opens that conversation); pop-up banners differ for message, reaction and announcement
- Filter Post sheet works: sort by Latest, Most like or Most comment, and limit by All, Today, This week or This month
- Tapping another user's name or avatar (feed, search, message header) opens their profile with details and posts, without the settings button
- Application Form Download asks for confirmation and saves a PDF
- Posts with a photo open the photo full screen

- Edit Profile has a birthday date picker
- Happening Now and Featured Organization cards redesigned with campus photos
